# 贪吃蛇 🐍

一个单文件的网页贪吃蛇，含 5 款皮肤。**无依赖、无构建、无后端** —— 双击 `index.html` 就能玩。

**[▶ 在线试玩](https://wow-create-01.github.io/snake-try/)**

---

## 玩法

| 操作 | 按键 |
| :--- | :--- |
| 转向 | `↑` `↓` `←` `→` 或 `W` `A` `S` `D` |
| 开始 / 暂停 / 继续 | `空格` |
| 重新开始 | `R` |
| 切换皮肤 | `1` ~ `5` 或点击棋盘下方的色板 |
| 移动端 | 在棋盘上滑动 |

撞墙或咬到自己就结束。每吃一颗果实得 10 分，每 50 分提速一档（150ms/步 → 最快 70ms/步）。

最高分和皮肤选择会存进 `localStorage`，关掉浏览器再打开还在。

## 皮肤

五款皮肤在**形态**上就有区别，不只是换色号：

| # | 皮肤 | 形态 |
| :-: | :--- | :--- |
| 1 | 翡翠 | 圆润的连续蛇身，绿→深青渐变 |
| 2 | 霓虹 | 细芯 + 大范围辉光，青→品红 |
| 3 | 岩浆 | 最粗壮，橙红亮度随时间脉动 |
| 4 | 幽灵 | 半透明 + 断续虚线，冰蓝色 |
| 5 | 彩虹 | 7 段色相沿身体流动的动画渐变 |

皮肤定义全部集中在 `index.html` 的 `SKINS` 数组里，每款是一份绘制参数（配色、线宽、头径、辉光、透明度、虚线），加一款只需要往数组里加一个对象。

## 实现上值得一提的两点

**1. 蛇是平滑移动的，不是逐格跳动。**
每步记录移动前的位置到 `prevSnake`，渲染时用累加器算出 0→1 的插值系数 `t`，在两次落格之间做线性插值。这是它看起来不廉价的关键。

**2. 输入有 2 格缓冲队列。**
如果按键直接改方向，快速连按「上→左」会在同一个 tick 内被解释成掉头，蛇当场咬死自己。队列让每次转向都基于「上一个待执行方向」判断合法性，这类莫名其妙的暴毙就消失了。

## 项目结构

```
snake-try/
├── index.html    # 全部内容：结构 + 样式 + 游戏逻辑
├── README.md
├── LICENSE
└── .gitignore
```

游戏逻辑内部的「存档层」是单独抽出来的（`store.read` / `store.write`），目前写 `localStorage`。将来接入后端只需要替换这一层，游戏逻辑不用动。

## 本地运行

不需要任何环境：

```bash
git clone https://github.com/Wow-create-01/snake-try.git
cd snake-try
```

然后双击 `index.html`。或者起个静态服务器：

```bash
python -m http.server 8080
# 打开 http://localhost:8080
```
