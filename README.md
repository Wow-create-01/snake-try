# 贪吃蛇 🐍

一个单文件的网页贪吃蛇，含 5 款皮肤。**无依赖、无构建、无后端** —— 双击 `index.html` 就能玩。

**[▶ 在线试玩](https://wow-create-01.github.io/snake-try/)**

---

## 玩法

| 操作 | 按键 |
| :--- | :--- |
| 转向 | `↑` `↓` `←` `→` 或 `W` `A` `S` `D` |
| 开始 / 暂停 / 继续 | `空格` |
| 重新开始 | `R` |
| 切换皮肤 | `1` ~ `5` 或点击棋盘下方的色板 |
| 移动端 | 在棋盘上滑动 |

每吃一颗果实得 10 分，每 50 分提速一档。速度档位可以在设置里调，默认「普通」是 150ms/步 → 最快 70ms/步。

**每吃一颗果实，棋盘上就长出一个障碍物**，整局累积——所以越到后面不光蛇更长、速度更快，可走的路也在变窄。撞墙、撞障碍物或咬到自己都会结束。

最高分、速度档位、皮肤选择和排行榜都存在 `localStorage`，关掉浏览器再打开还在。

## 设置

点右上角 HUD 里的齿轮打开。里面有两项：

**速度** —— 四档，会同时改变起始速度和速度上限。分数越高越接近上限这一点不变，所以难度曲线还在，只是整体平移。

| 档位 | 起始 | 上限 |
| :--- | ---: | ---: |
| 慢 | 200ms/步 | 115ms/步 |
| 普通（默认） | 150ms/步 | 70ms/步 |
| 快 | 112ms/步 | 55ms/步 |
| 极速 | 84ms/步 | 44ms/步 |

**皮肤** —— 见下节。

打开设置会**自动暂停**游戏（免得调参数的时候蛇撞死），关掉后自动继续。按 `Esc` 或点面板外也能关。设置面板打开期间游戏按键全部屏蔽——这时候按空格不该把游戏开起来。

## 排行榜

固定在页面右上角，不占文档流。记录**本机**前 5 名，每局结束自动入榜，新成绩会在榜上高亮到下一局开始。按分数降序，同分则用时短的排前面。得分为 0 的局不入榜。

窄屏（< 860px）放不下右上角的浮层，会自动落回棋盘下方。

目前没有玩家名——本地排行榜没有账号体系，加个名字输入框只会让每局结束多一步操作。等接入后端有账号了，名字自然就有了。

榜单右侧的「清空」可以重置（有二次确认）。

## 皮肤

五款皮肤在**形态**上就有区别，不只是换色号：

| # | 皮肤 | 形态 |
| :-: | :--- | :--- |
| 1 | 翡翠 | 圆润的连续蛇身，绿→深青渐变 |
| 2 | 霓虹 | 细芯 + 大范围辉光，青→品红 |
| 3 | 岩浆 | 最粗壮，橙红亮度随时间脉动 |
| 4 | 幽灵 | 半透明 + 断续虚线，冰蓝色 |
| 5 | 彩虹 | 7 段色相沿身体流动的动画渐变 |

在设置面板里选，也可以直接按数字键 `1`-`5`。

皮肤定义全部集中在 `index.html` 的 `SKINS` 数组里，每款是一份绘制参数（配色、线宽、头径、辉光、透明度、虚线），加一款只需要往数组里加一个对象。

## 实现上值得一提的三点

**1. 蛇是平滑移动的，不是逐格跳动。**
每步记录移动前的位置到 `prevSnake`，渲染时用累加器算出 0→1 的插值系数 `t`，在两次落格之间做线性插值。这是它看起来不廉价的关键。

**2. 输入有 2 格缓冲队列。**
如果按键直接改方向，快速连按「上→左」会在同一个 tick 内被解释成掉头，蛇当场咬死自己。队列让每次转向都基于「上一个待执行方向」判断合法性，这类莫名其妙的暴毙就消失了。

**3. 障碍物生成有两条公平性约束。**
随机撒障碍物会产生两种让人恼火的死法，都做了排除：

- **不贴着蛇头生成**（曼哈顿距离 3 格以内不放）。否则在 70ms 一步的速度下，障碍物可能贴脸出现，玩家根本没有反应时间。
- **不把食物封死**。每放一个障碍物前，从蛇头做一次 BFS，确认食物仍然可达；会切断通路的位置直接跳过。否则这局会变成无解，玩家只能等死。

两条都不满足时宁可不生成——障碍物少一个，总好过一局没法玩。

## 项目结构

```
snake-try/
├── index.html    # 全部内容：结构 + 样式 + 游戏逻辑
├── README.md
├── LICENSE
└── .gitignore
```

游戏逻辑内部的「存档层」是单独抽出来的（`store.read` / `store.write`），排行榜的读写也集中在 `loadBoard` / `submitScore` 两个函数里。将来接入后端只需要替换这几处，排序、渲染、名次计算的逻辑都不用动。

## 本地运行

不需要任何环境：

```bash
git clone https://github.com/Wow-create-01/snake-try.git
cd snake-try
```

然后双击 `index.html`。或者起个静态服务器：

```bash
python -m http.server 8080
# 打开 http://localhost:8080
```
